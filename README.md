# Movie Ticket Booking

> **Abstract** : This project introduces a decentralized movie ticketing DApp that replaces vulnerable central databases with smart contract logic to combat server outages, high fees, and ticket scalping. Built with Solidity and React, the platform enables theater owners to issue screening tickets as secure Non-Fungible Tokens (NFTs) directly to user wallets. The smart contract enforces fixed seat capacities, zero-downtime availability, and programmed resale constraints, demonstrating Web3's practical utility for secure, equitable event management.
